# Pi MVP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement inline.

**Goal:** Run and inspect a three-session Pi workflow using Command Code.
**Architecture:** A small SDK adapter owns sessions; an editable workflow coordinates
two specialists and one coordinator; the CLI owns credentials, artifacts, and signals.
**Tech Stack:** Node >=22.19, TypeScript, Pi SDK 1.4.0, Node test runner.
**Spec:** `docs/superpowers/specs/2026-10-29-pi-mvp-design.md`

## Global Constraints

No key output or copies; no inherited tools/resources; separate `pi-lab/` directory.

must cancel work; partial artifacts must survive failure; SDK errors must not be
mistaken for successful assistant text.
